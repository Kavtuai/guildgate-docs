# Release notes

## GuildGate 1.0.0

The stable surface covers:

- guarded writes and optimistic concurrency
- transaction hooks, cache invalidation, and outbox records
- renewable distributed locks and fencing tokens
- timeouts, retries, and circuit breakers
- operator and session management
- WebSocket, SSE, sequencing, and replay
- Fastify, Express, Hono, and discord.js adapters
- PostgreSQL, Redis, and custom store contracts
- OpenTelemetry hooks, status monitoring, and analytics examples
- migration guidance, operating limits, and security response material

## Documentation site 0.3.0

- Turkish and English content now share one information architecture.
- Package references use version `1.0.0`.
- The verification console works in both languages.
- The verification console now states its browser boundary and data-handling behavior directly.
- Architecture, threat model, store contracts, resilience, telemetry, migration, and testing pages were added.
- The social card and favicon use the supplied GuildGate artwork.
