# Release notes

## GuildGate 1.1.0 · July 26, 2026

### Transactions and idempotency

- PostgreSQL commit is separated from post-commit callback execution. A callback failure no longer creates a false rollback or repeats a committed domain write.
- Nested PostgreSQL work now uses savepoints, savepoint rollback, and callback propagation after successful release.
- Idempotency records now carry reservation ownership. Memory, Redis, and PostgreSQL stores use compare-and-set for renew, complete, and fail.
- Action deadlines return at the configured boundary even when underlying work ignores the cancellation signal.
- `reliability.maximumLateSettlementMs` bounds reservation and lease retention during late settlement.

### Stores and security

- Official memory, Redis, and PostgreSQL stores enforce per-user session caps atomically.
- Audit paging uses an opaque `(createdAt, id)` cursor.
- Redis cache retagging, stale-tag cleanup, and deletion are atomic; tag indexes receive TTLs.
- PostgreSQL rate-limit bucket updates are serialized with transaction advisory locks.
- Fail-closed audit runs before commit inside the required transaction.
- Discord OAuth refresh uses a distributed single-flight lease and rereads credentials after lock acquisition.
- Production URL validation covers IPv4, IPv6, unspecified, and IPv4-mapped loopback targets.
- Fastify, Express, and Hono metadata clears expired or revoked session cookies.

### Realtime and outbox

- Socket.IO subscribe, unsubscribe, and heartbeat events pass through the same payload, rate, activity, and subscription controls as WebSocket messages.
- Socket.IO acknowledgements, replay, and transport backpressure are supported.
- Subscription capacity is rechecked after asynchronous authorization.
- Failed sends remove connection state, while revocation listener failures are isolated.
- Outbox claim leases, batches, and concurrency are bounded; persisted publisher errors are sanitized and shortened.

### Verification

- 76 deterministic tests passed and 0 failed.
- Two live-service definitions skipped locally run in CI with PostgreSQL 17 and Redis 8.
- Coverage: 86.56% lines, 77.15% branches, 78.08% functions.
- All 16 public export paths and 3 CLI help targets were verified in an empty consumer project.
- The 5,000-operation, concurrency-10 in-memory load regression completed with zero failures.

## Migration from 1.0.0

Projects with custom adapters should:

- implement adapter contract `1.1`
- add idempotency reservation ownership
- enforce atomic session caps
- support audit cursor paging and outbox claims
- separate post-commit callback behavior
- route Socket.IO events through hub controls

Use [migration and versioning](./referans/gecis-ve-surumleme.mdx) for details.
