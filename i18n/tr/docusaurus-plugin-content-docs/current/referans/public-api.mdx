# Dışa açık API

## Çekirdek

```ts
import {
  createGuildGate,
  createMemoryStoreBundle,
  composeStores,
  createMemoryTransactionAdapter,
} from "@kavtuai/guildgate";
```

`GuildGateKernel` ana üyeleri:

| Üye | Görev |
| --- | --- |
| `config` | Doğrulanmış yapılandırma |
| `sessions` | `SessionManager` |
| `cache` | `CacheManager` |
| `cookie` | Çözülen cookie ayarı |
| `csrf.issue/verify` | Session-bound token üretme/doğrulama |
| `action` | Action tanımı oluşturma |
| `execute` | Request envelope yürütme |
| `createSession` | Session, token, CSRF ve cookie üretme |

| `revokeUserSessions` | Kullanıcının tüm session'larını iptal |
| `owner` | Bakım ve blok politikaları |

## Store yüzeyi

`GuildGateStores` on üye içerir:

```ts
interface GuildGateStores {
  sessions: SessionStore;
  oauthStates: OAuthStateStore;
  credentials: OAuthCredentialStore;
  rateLimits: RateLimitStore;
  cache: CacheStore;
  idempotency: IdempotencyStore;
  locks: LockStore;
  audit: AuditStore;
  outbox: OutboxStore;
  policies: PolicyStore;
}
```

`1.1.0` ile önemli ek yetenekler:

- `SessionStore.create(record, maximumSessionsPerUser)`
- reservation owner alanı ve idempotency `renew/complete/fail` sonucu
- `AuditStore.listPage()`
- `OutboxStore.claim()`
- lease ve fencing token desteği
