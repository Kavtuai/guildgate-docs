# Güvenlik

Dokümantasyon sitesinde güvenlik açığı bulursan herkese açık hata kaydında gizli anahtar, belirteç veya kişisel veri paylaşma. Paket deposunun güvenlik bildirim kanalını kullan.

Bu site statik olarak yayımlanır. İstemci koduna Discord istemci sırrı, bot belirteci, OAuth belirteci, oturum anahtarı veya veritabanı bağlantısı eklenmemelidir.
