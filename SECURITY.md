# Güvenlik

Dokümantasyon sitesinde güvenlik açığı bulursan herkese açık hata kaydında gizli anahtar, belirteç veya kişisel veri paylaşma. Ana GuildGate deposunun güvenlik bildirim kanalını kullan.

Site statik olarak yayımlanır. İstemci koduna Discord istemci sırrı, bot belirteci, OAuth belirteci, oturum anahtarı veya veritabanı bağlantısı eklenmemelidir.

Komut laboratuvarı gerçek kabuk veya JavaScript kodu çalıştırmaz. İzin listesi dışına çıkan, ağ erişimi ekleyen veya girdiyi kod olarak değerlendiren değişiklik güvenlik incelemesi olmadan kabul edilmez.
