# CSRF ve origin kontrolü

GuildGate yazma isteğinde iki ayrı koşul arar:

1. İstek origin'i izin verilen adreslerden biri olmalı.
2. CSRF belirteci açık oturuma bağlı olmalı.

CORS bu kontrollerin yerine geçmez. CORS, tarayıcının yanıtı okuyup okuyamayacağını etkiler; istek sunucuya yine ulaşabilir. Bu nedenle origin sunucuda ayrıca doğrulanır.

## İzin verilen origin'ler

```ts
security: {
  allowedOrigins: [
    "https://panel.example.com",
  ],
}
```

Joker karakter kullanma. Protokol, host ve port birlikte karşılaştırılır.
