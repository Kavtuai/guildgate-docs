# CSRF ve origin

GuildGate iki ayrı kontrol kullanır: tam origin eşleşmesi ve oturuma bağlı CSRF belirteci. Biri diğerinin yerine geçmez.

## Tam origin eşleşmesi

`https://panel.example.com`, aşağıdaki adreslerle aynı origin değildir:

- `http://panel.example.com`
- `https://admin.panel.example.com`
- `https://panel.example.com:8443`
- `https://panel.example.com.evil.test`

Origin değerini substring, suffix veya düzenli ifadeyle gevşetme. URL ayrıştırıcısından çıkan `origin` alanını izin kümesiyle birebir karşılaştır.

## Oturuma bağlı CSRF

CSRF belirteci oturum kimliğiyle kriptografik olarak bağlanır. Başka oturumdan alınan geçerli görünümlü değer kabul edilmez.

İstemci yazma isteğinde:

1. Oturum çerezini otomatik gönderir.
2. CSRF değerini özel header ile ekler.
3. Sunucu origin, session ve CSRF bağını doğrular.

## Production retleri

GuildGate production profilinde boş origin listesi, HTTP origin, localhost origin ve kısa CSRF sırrını reddeder.

## Proxy notu

Origin kontrolü istemci IP'sine bağlı değildir. IP tabanlı rate limit veya audit hashing kullanıyorsan yalnızca güvenilir proxy zincirinden gelen adresi kabul et.
