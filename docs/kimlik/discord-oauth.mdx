# Discord OAuth

GuildGate, Discord girişini authorization code modeliyle ele alır. Login başlangıcında kısa ömürlü bir `state` kaydı açar ve tarayıcıya ayrı bir nonce çerezi verir. Callback sırasında state, nonce, süre ve tek kullanımlık tüketim birlikte kontrol edilir.

## Giriş sırası

```text
Tarayıcı → login başlangıcı
Sunucu   → state kaydı + nonce çerezi
Tarayıcı → Discord yetkilendirme sayfası
Discord  → callback?code=...&state=...
Sunucu   → state + nonce + callback doğrulaması
Sunucu   → code değişimi ve Discord kimliği
Sunucu   → şifreli OAuth kaydı + opak oturum
```

## State store

`OAuthStateStore` şu özellikleri korumalıdır:

- tek kullanımlık tüketim
- kısa yaşam süresi
- tarayıcı nonce bağı
- aynı state için atomik consume
- hata durumunda tekrar kullanılmama

## OAuth credential store

`OAuthCredentialStore`, erişim ve yenileme token'larını düz metin tutmamalı. GuildGate şifreleme işini çağıranın sağladığı token cipher veya keyring ile yürütür. Anahtar sürümü kayıtla birlikte tutulursa eski token'ları yeni anahtarla kademeli olarak çevirebilirsin.

## Callback kuralları

- Production callback adresi HTTPS kullanmalı.
- Discord Developer Portal ve uygulama ayarı birebir eşleşmeli.
- Callback hatası kullanıcıya token, state, nonce veya Discord yanıt gövdesi göstermemeli.
- Başarılı girişten sonra eski oturumu döndürmek yerine yeni opak oturum aç.
