# `guildgate-doctor`

Doctor, GuildGate için gerekli ortam ve güvenlik koşullarını yerel süreçte kontrol eder.

```bash
npx guildgate-doctor
```

Makine tarafından okunabilir çıktı:

```bash
npx guildgate-doctor --json
```

## Kontrol başlıkları

- Node.js sürümü
- environment ve `baseUrl`
- HTTPS callback
- origin listesi
- CSRF ve audit hashing sırrı
- oturum çerezi
- store yerleşimi
- Redis ad alanı
- token cipher/keyring
- owner kimlikleri

## Çıktı güvenliği

Doctor bir sırrın varlığını ve uzunluk koşulunu kontrol edebilir; değerin kendisini rapora yazmaz. JSON çıktısını CI log'unda kullanmadan önce yine de platform log saklama politikanı gözden geçir.

## CI kullanımı

Doctor risk bulduğunda sıfırdan farklı çıkış kodu vermelidir. Dağıtım adımını bu sonuçla durdur:

```bash
npx guildgate-doctor --json
npm test
npm run pack:check
```
