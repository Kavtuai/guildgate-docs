# `guildgate-doctor`

Tanı komutu proje ve çalışma ortamındaki yaygın yapılandırma sorunlarını raporlar.

```bash
npx guildgate-doctor
```

CI veya başka bir araç için JSON çıktısı:

```bash
npx guildgate-doctor --json
```

Yardım:

```bash
npx guildgate-doctor --help
```

Tanı başarılı olsa bile [üretim güvenlik listesini](/docs/uretim/guvenlik-kontrol-listesi) uygula. Komut, ürününe özel rol sırasını ve veri saklama kararını bilemez.
