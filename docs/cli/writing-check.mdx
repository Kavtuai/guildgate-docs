# `guildgate-writing-check`

Bu komut, bulunduğun projedeki dokümantasyon dosyalarını kontrol eder. Eksik doküman klasörlerini atlar; mevcut metinlerde bilinen yazım artıklarını arar.

```bash
npx guildgate-writing-check
```

Başka bir kökü denetlemek için:

```bash
npx guildgate-writing-check --root ./docs-site
```

Yardım:

```bash
npx guildgate-writing-check --help
```

Bu sitede ayrıca `npm run editorial:check` komutu vardır. Siteye özel Türkçe kalıpları ve istemeden yapıştırılmış araç işaretlerini tarar.
