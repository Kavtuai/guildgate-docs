# `guildgate-writing-check`

Bu komut, projedeki dokümantasyon dosyalarını tarar. Eksik klasörleri atlar; bulunan metinlerde bilinen yazım artıklarını, doldurulmamış alanları ve bozuk araç işaretlerini arar.

```bash
npx guildgate-writing-check
```

Başka bir kök dizin:

```bash
npx guildgate-writing-check --root ./docs-site
```

Yardım:

```bash
npx guildgate-writing-check --help
```

Bu depoda daha dar bir Türkçe denetim de vardır:

```bash
npm run editorial:check
```

Komut bir metnin insan mı makine mi tarafından yazıldığını söylemez. Ama yayıma girmemesi gereken placeholder, araç etiketi, bozuk atıf ve tekrar eden kalıpları yakalar. Kuralların ayrıntısı [yazı standardı](/docs/katki/yazi-standardi) sayfasındadır.
