# Sorun giderme

## OAuth geri dönüş adresi uyuşmuyor

Discord Developer Portal'daki yönlendirme adresi ile sunucu ayarını karakter karakter karşılaştır. Protokol, yol ve sondaki eğik çizgi farklıysa Discord isteği reddeder.

## CSRF hatası alıyorum

Şu sırayla kontrol et:

- İstek veri değiştiren bir yöntem kullanıyor mu?
- Oturum açık mı?
- CSRF değeri aynı oturumdan mı üretildi?
- Beklenen üstbilgi gönderiliyor mu?
- Ön yüz ve API origin adresleri `allowedOrigins` listesiyle birebir eşleşiyor mu?

## İki instance arasında oturum kayboluyor

Bellek deposu kullanılıyor olabilir. Paylaşılan kısa ömürlü kayıtları Redis'e, kalıcı kayıtları ana veritabanına taşı.

## Aynı ayar iki kez kaydediliyor

İstemci isteği yeniden deniyor olabilir. İşleme tekrarlı istek kapsamı ekle ve aynı işlem için aynı anahtarın gönderildiğini doğrula.

## Rol işlemi yetki hatası veriyor

Kullanıcı izni ile bot rol sırasını ayrı kontrol et. Botun `MANAGE_ROLES` izni olsa bile kendi rolünün üstündeki rolü yönetemez.

## Gerçek zamanlı bağlantı açık, kanal boş

Bağlantı oturumu geçerli olsa da abonelik yetkisi reddedilmiş olabilir. Kanal yetki kontrolünü, hedef `guildId` değerini ve korelasyon kimliğini sunucu günlüğünde incele.

## GitHub Pages CSS olmadan açılıyor

Özel alan adı hazır değilken `DOCS_DOMAIN=jsorg` kullanma. Depo yolu üzerinden yayında değişkeni kaldır. js.org DNS kaydı açıldığında tekrar ekle.
