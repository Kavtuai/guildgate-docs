# Sorun giderme

## Production başlangıçta kapanıyor

Önce doctor çalıştır:

```bash
npx guildgate-doctor --json
```

HTTP `baseUrl`, localhost origin, kısa sır, Secure olmayan çerez veya eksik kalıcı store production profilinde başlangıcı durdurabilir.

## Discord callback uyuşmuyor

Developer Portal'daki callback ile uygulamadaki adresi karakter karakter karşılaştır. Protokol, port, path ve trailing slash farkı uyuşmazlık üretir.

## Her yazma isteği CSRF hatası veriyor

- CSRF değerini doğru header ile gönder.
- Oturum çereziyle aynı origin üzerinden istek yap.
- Rotasyon sonrası eski CSRF değerini kullanma.
- Proxy'nin özel header'ı silmediğini kontrol et.

## Origin izin listesinde görünüyor ama reddediliyor

URL'nin `origin` değerini yazdır ve tam karşılaştır. Path izin listesine dahil değildir; protokol ve port dahildir.

## Birden fazla instance farklı sonuç veriyor

Bellek store'u production'da kalmış olabilir. Session, rate limit, idempotency, cache ve lock verisini instance'lar arasında ortaklaştır.

## Kilit sürekli kayboluyor

Action timeout, kilit TTL ve renewal aralığını birlikte kontrol et. Uzun DB sorgusu abort sinyalini dinlemiyorsa kilit süresi dolduktan sonra yazma devam edebilir.

## Realtime olayları eksik

Sequence değerini, replay retention süresini ve istemcinin son gördüğü cursor'u kontrol et. Session revocation veya geri basınç kapanması da yeniden bağlanma gerektirir.

## Kullanıcıya iç hata görünüyor

Framework bağdaştırıcısındaki error mapper'ı kontrol et. Kullanıcı yanıtına `error.message`, stack veya store hatasını doğrudan koyma; sabit GuildGate kodunu yerelleştirilmiş metne çevir.
