# İlk yapılandırma

`createGuildGate()` uygulama kimliğini, güvenlik sınırlarını, dilleri ve store paketini tek nesnede alır.

```ts
const gate = createGuildGate({
  app: {
    name: "My Discord Dashboard",
    environment: "production",
    baseUrl: "https://panel.example.com",
  },
  owners: ["123456789012345678"],
  locale: {
    default: "en",
    messages: {
      en: {
        MAINTENANCE_MODE: "Settings are unavailable during maintenance.",
      },
      tr: {
        MAINTENANCE_MODE: "Ayar değişiklikleri bakım bitene kadar kapalı.",
      },
    },
  },
  security: {
    allowedOrigins: ["https://panel.example.com"],
    csrfSecret: process.env.GUILDGATE_CSRF_SECRET!,
    auditIpSalt: process.env.GUILDGATE_AUDIT_IP_SALT!,
    session: {
      ttlMs: 12 * 60 * 60_000,
      idleTimeoutMs: 30 * 60_000,
      rotateAfterMs: 15 * 60_000,
      maximumSessionsPerUser: 5,
    },
  },
  stores,
});
```

## Uygulama alanları

| Alan | Karar |
| --- | --- |
| `app.name` | Log ve operatör ekranlarında görünen uygulama adı |
| `app.environment` | Güvenlik varsayımlarını ve store ad alanlarını ayıran ortam |
| `app.baseUrl` | Dashboard'un dışarıdan erişilen temel adresi |
| `owners` | Sahip işlemlerini kullanabilen Discord kullanıcı kimlikleri |
| `locale.default` | Varsayılan hata ve durum dili |
| `locale.messages` | Uygulamaya ait hata kodu metinleri |

## Oturum politikası

`ttlMs` mutlak sınırı, `idleTimeoutMs` kullanılmayan oturumun kapanma süresini, `rotateAfterMs` belirteç yenileme aralığını, `maximumSessionsPerUser` ise açık oturum üst sınırını belirler.

Süreleri birbirinden bağımsız düşünme. Çok uzun mutlak süre ve çok kısa yenileme, ele geçirilen oturumu tek başına durdurmaz; iptal store'u da çalışır durumda olmalı.

## Üretim korumaları

GuildGate production profilinde şunları reddeder:

- HTTP `baseUrl`
- boş origin listesi
- HTTP veya localhost origin
- Secure özelliği kapalı oturum çerezi
- HTTP Discord callback adresi
- kısa CSRF veya audit hashing sırrı

Tüm seçenekler için [yapılandırma referansını](../referans/yapilandirma.mdx) aç.
