# İlk yapılandırma

Bu örnek yerel geliştirme içindir. Bellek deposundaki kayıtlar süreç kapandığında silinir.

```ts
import {
  createGuildGate,
  createMemoryStoreBundle,
} from "@kavtuai/guildgate";

const stores = createMemoryStoreBundle();

const gate = createGuildGate({
  app: {
    name: "GuildGate Yönetim Paneli",
    environment: "development",
    baseUrl: "http://localhost:3000",
  },
  owners: [process.env.BOT_OWNER_ID!],
  locale: {
    default: "tr",
    messages: {
      tr: {
        MAINTENANCE_MODE: "Bakım sırasında ayar değişiklikleri duraklatıldı.",
      },
    },
  },
  security: {
    allowedOrigins: ["http://localhost:3000"],
    csrfSecret: process.env.GUILDGATE_CSRF_SECRET!,
    auditIpSalt: process.env.GUILDGATE_AUDIT_IP_SALT!,
    session: {
      ttlMs: 12 * 60 * 60_000,
      idleTimeoutMs: 30 * 60_000,
      rotateAfterMs: 15 * 60_000,
      maximumSessionsPerUser: 5,
    },
  },
  stores,
});
```

## Alanların görevi

`app` uygulama adını, ortamı ve temel adresi tanımlar. `owners` uygulama sahiplerinin Discord kullanıcı kimliklerini içerir. `security.allowedOrigins` yalnızca listede birebir bulunan origin adreslerini kabul eder.

| Alan | Görevi |
| --- | --- |
| `ttlMs` | Oturumun toplam ömrü |
| `idleTimeoutMs` | İşlem yapılmadığında oturumun kapanacağı süre |
| `rotateAfterMs` | Oturum belirtecinin yenilenme aralığı |
| `maximumSessionsPerUser` | Kullanıcı başına açık oturum üst sınırı |

## Üretim için değiştirilecekler

Bellek deposunu yerel geliştirme ve test dışında kullanma. Yeniden başlatmadan sonra kalması gereken kayıtları kendi veritabanına bağla. Dağıtık ve kısa ömürlü kayıtlar için Redis kullan.
