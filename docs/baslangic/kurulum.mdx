# Kurulum

## Gereksinimler

- Node.js `22.12.0` veya üzeri
- Sunucu tarafında çalışan TypeScript ya da modern JavaScript projesi
- Discord OAuth uygulaması
- Üretimde HTTPS

## Paketi ekle

```bash
npm install @kavtuai/guildgate
```

GuildGate, Fastify veya Express'i kendi bağımlılığı olarak kurmaz. Mevcut sunucunun istek ve yanıt nesnelerini ince bağdaştırıcılarla kullanır.

## İlk tanı

```bash
npx guildgate-doctor
```

Makine tarafından okunabilir çıktı:

```bash
npx guildgate-doctor --json
```

Tarayıcıda örnek sonucu görmek için [komut laboratuvarını](/docs/araclar/komut-laboratuvari) açabilirsin. Bu araç gerçek proje dosyalarını okumaz; belgelenen kontrolleri sabit örneklerle gösterir.

## Ortam değişkenleri

Yerel örnek için en az şu değerleri tanımla:

```env
GUILDGATE_CSRF_SECRET=uzun-ve-rastgele-bir-deger
GUILDGATE_AUDIT_IP_SALT=ayri-uzun-ve-rastgele-bir-deger
BOT_OWNER_ID=discord-kullanici-id
```

OAuth istemci sırrı, bot belirteci, şifreleme anahtarı ve Redis bağlantısı da sunucu ortamında tutulmalıdır. Bunları istemci paketine veya herkese açık depo geçmişine koyma.

:::warning Sırları kaynak koduna yazma
`.env` dosyasını Git'e ekleme. Üretim değerlerini dağıtım platformunun gizli değişken alanında sakla.
:::
