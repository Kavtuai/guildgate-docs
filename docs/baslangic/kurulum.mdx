# Kurulum

## Gereksinimler

- Node.js `22.12.0` veya üzeri
- Sunucu tarafında çalışan TypeScript ya da modern JavaScript projesi
- Discord OAuth uygulaması
- Üretimde HTTPS

## Paketi ekle

```bash
npm install @kavtuai/guildgate
```

Paket TypeScript bildirimlerini kendi içinde taşır. Fastify, Express, Hono, Redis istemcisi ve veritabanı sürücüsü proje seçimine bağlı kaldığı için bunları ayrıca kurarsın.

## Kurulumu doğrula

```bash
node ./node_modules/@kavtuai/guildgate/bin/guildgate-doctor.mjs
```

Paket komutu `node_modules/.bin` üzerinden görünüyorsa kısa biçimi de kullanabilirsin:

```bash
npx guildgate-doctor
```

JSON çıktısı:

```bash
npx guildgate-doctor --json
```

Doctor komutu ortam değerlerini yerel süreçte okur. Sırları dışarı göndermez ve değerlerin kendisini rapora yazmaz.

## Import kontrolü

```ts
import {
  createGuildGate,
  createMemoryStoreBundle,
} from "@kavtuai/guildgate";
```

Dahili `src/` veya `dist/` yollarından import yapma. Yayımlanan ana paket ve alt yolları kullan.
