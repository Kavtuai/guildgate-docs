# Yapılandırma referansı

## `app`

| Alan | Açıklama |
| --- | --- |
| `name` | Uygulama ve audit bağlamındaki ad |
| `environment` | Geliştirme, staging veya production ayrımı |
| `baseUrl` | Dışarıdan erişilen dashboard adresi |

## `owners`

Sahip işlemlerini kullanabilen Discord kullanıcı kimlikleri. Sahip olmak session, origin, CSRF, rate limit veya audit kontrolünü kapatmaz.

## `locale`

| Alan | Açıklama |
| --- | --- |
| `default` | Varsayılan mesaj dili |
| `messages` | Hata kodu bazlı TR/EN veya özel dil metinleri |

## `security`

| Alan | Açıklama |
| --- | --- |
| `allowedOrigins` | Tam eşleşmeyle kabul edilen origin listesi |
| `csrfSecret` | CSRF imzası için ayrı sır |
| `auditIpSalt` | Ham IP saklamadan bağlam üretmek için ayrı salt |
| `session.ttlMs` | Mutlak oturum süresi |
| `session.idleTimeoutMs` | Boşta kalma sınırı |
| `session.rotateAfterMs` | Opak belirteç yenileme aralığı |
| `session.maximumSessionsPerUser` | Kullanıcı başına açık oturum üst sınırı |

## `stores`

`GuildGateStores` sözleşmesini karşılayan paket. `createMemoryStoreBundle()` yalnızca geliştirme/test için uygundur. Production store yerleşimi için [depo sözleşmelerine](../depolama/depo-sozlesmeleri.mdx) bak.

## İleri ayarlar

`1.0.0` action yüzeyi transaction hook, cache invalidation, retry, timeout, circuit breaker, dağıtık kilit ve fencing token davranışlarını destekler. Bu alanların tam tipini kurulu paketin TypeScript bildirimlerinden al.
