# Yapılandırma referansı

## `app`

| Alan | Açıklama |
| --- | --- |
| `name` | Log ve hata bağlamında kullanılan uygulama adı |
| `environment` | `development`, `staging` veya üretim ortamı |
| `baseUrl` | Yönetim panelinin temel adresi |

## `owners`

Uygulama sahibi kabul edilen Discord kullanıcı kimlikleri. Sahip yetkisi istek güvenliği kontrollerini kapatmamalıdır.

## `locale`

`default` varsayılan hata dilini belirler. `messages`, hata kodlarını projeye uygun metinlerle değiştirmene izin verir.

## `security`

| Alan | Açıklama |
| --- | --- |
| `allowedOrigins` | Tam eşleşmeyle kabul edilen origin adresleri |
| `csrfSecret` | CSRF belirteçleri için ayrı sır |
| `auditIpSalt` | IP değerini denetim kaydında düz tutmamak için salt |
| `session.ttlMs` | Oturumun toplam ömrü |
| `session.idleTimeoutMs` | Boşta kalma sınırı |
| `session.rotateAfterMs` | Belirteç rotasyon süresi |
| `session.maximumSessionsPerUser` | Kullanıcı başına açık oturum sınırı |

## `stores`

Oturum, OAuth durum kaydı, tekrarlı istek koruması, istek sınırı, kilit ve denetim kaydı için depo uygulamalarıdır. Yerel örnekte bellek deposu kullanılabilir. Üretimde kayıt türüne göre kalıcı veritabanı ve Redis seçilir.
