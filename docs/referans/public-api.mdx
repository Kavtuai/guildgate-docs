## Kernel

```ts
import {
  createGuildGate,
  createMemoryStoreBundle,
  composeStores,
  createMemoryTransactionAdapter,
} from "@kavtuai/guildgate";
```

Main `GuildGateKernel` members:

| Member | Purpose |
| --- | --- |
| `config` | Validated configuration |
| `sessions` | `SessionManager` |
| `cache` | `CacheManager` |
| `cookie` | Resolved cookie settings |
| `csrf.issue/verify` | Session-bound token creation and verification |
| `action` | Create an action definition |
| `execute` | Execute a request envelope |
| `createSession` | Create session, token, CSRF, and cookie |
| `revokeSession` | Revoke one session |
| `revokeUserSessions` | Revoke all sessions for a user |
| `owner` | Maintenance and block policies |

## Store surface

`GuildGateStores` has ten members:

```ts
interface GuildGateStores {
  sessions: SessionStore;
  oauthStates: OAuthStateStore;
  credentials: OAuthCredentialStore;
  rateLimits: RateLimitStore;
  cache: CacheStore;
  idempotency: IdempotencyStore;
  locks: LockStore;
  audit: AuditStore;
  outbox: OutboxStore;
  policies: PolicyStore;
}
```

Important `1.1.0` capabilities:

- `SessionStore.create(record, maximumSessionsPerUser)`
- reservation ownership and idempotency `renew/complete/fail` results
- `AuditStore.listPage()`
- `OutboxStore.claim()`
- leases and fencing tokens

## Testing helpers

```ts
import { createGuildGateTestHarness } from "@kavtuai/guildgate/testing";
import { runStoreContract } from "@kavtuai/guildgate/contracts";
```

The test harness creates a kernel with memory stores and safe defaults. Real adapter service tests are still required to verify production behavior.
