# Dışa açık API

Bu sayfa `0.1.0` sürümündeki ana dışa aktarımları gösterir. Parametre ve dönüş tiplerinde kurulu paketin TypeScript bildirimlerini esas al.

| Dışa aktarım | Import yolu | Görevi |
| --- | --- | --- |
| `createGuildGate` | `@kavtuai/guildgate` | Ana GuildGate örneğini oluşturur |
| `createMemoryStoreBundle` | `@kavtuai/guildgate` | Yerel geliştirme ve test depolarını kurar |
| `composeStores` | `@kavtuai/guildgate` | Farklı depo uygulamalarını birleştirir |
| `createRedisEphemeralStores` | `@kavtuai/guildgate/redis` | Kısa ömürlü Redis depolarını kurar |
| `fromNodeRedis` | `@kavtuai/guildgate/redis` | Node Redis istemcisini beklenen arayüze uyarlar |
| `fastifyActionHandler` | `@kavtuai/guildgate/fastify` | İşlemi Fastify rotasına bağlar |
| `expressActionHandler` | `@kavtuai/guildgate/express` | İşlemi Express rotasına bağlar |
| `createRealtimeHub` | ana paket dışa aktarımı | Yetkili gerçek zamanlı bağlantı merkezini oluşturur |
| `createDiscordGuildAuthorizer` | `@kavtuai/guildgate/discord` | Discord kullanıcı ve bot izinlerini denetler |

## Gate üzerinde kullanılan alanlar

- `gate.action(...)`
- `gate.cache`
- Oturum, CSRF, denetim ve gerçek zamanlı servisler

Paket alt yollarını IDE otomatik tamamlama ve yayımlanan `exports` alanıyla doğrula. Dahili dosya yollarından import yapma.
