# Dışa açık API

Bu sayfa `1.0.0` sürümündeki doğrulanmış ana export'ları özetler. Parametre ve dönüş tiplerinde kurulu paketin TypeScript bildirimlerini esas al.

## Çekirdek

| Export | Görev |
| --- | --- |
| `createGuildGate` | Ana çekirdeği oluşturur |
| `createMemoryStoreBundle` | Geliştirme ve test store'larını kurar |
| `composeStores` | Birden fazla store paketini birleştirir |
| `createRealtimeHub` | Yetkili realtime abonelik merkezini kurar |
| `RealtimeConnection` | Bir bağlantının kimlik ve teslim bağlamını temsil eder |

## Store tipleri

- `GuildGateStores`
- `SessionStore`
- `OAuthStateStore`
- `OAuthCredentialStore`
- `RateLimitStore`
- `CacheStore`
- `IdempotencyStore`
- `LockStore`
- `AuditStore`
- `OutboxStore`
- `PolicyStore`

## Redis

| Export | Import yolu | Görev |
| --- | --- | --- |
| `createRedisEphemeralStores` | `@kavtuai/guildgate/redis` | Kısa ömürlü store paketini kurar |
| `fromNodeRedis` | `@kavtuai/guildgate/redis` | Node Redis istemcisini gereken sözleşmeye çevirir |

## HTTP

| Export | Import yolu |
| --- | --- |
| `fastifyActionHandler` | `@kavtuai/guildgate/fastify` |
| `expressActionHandler` | `@kavtuai/guildgate/express` |

Paket Hono ve discord.js bağdaştırıcıları da içerir. Tam export adını kurulu sürümün `exports` alanı ve IDE otomatik tamamlamasıyla doğrula.

## Gate yöntemleri

Doğrulanmış yüzeyde şu işlemler bulunur:

- `gate.action(...)`
- `gate.owner.setMaintenance(...)`
- `gate.owner.block(...)`
- `gate.owner.unblock(...)`
- `gate.revokeUserSessions(...)`

Dahili dosya yollarından import yapma; semver güvencesi yalnızca yayımlanan export yüzeyi için geçerlidir.
