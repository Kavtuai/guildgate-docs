# Hatalar ve diller

GuildGate iç kararları sabit hata kodlarıyla temsil eder. Kullanıcıya gösterilecek metni `locale.messages` üzerinden seçebilirsin.

```ts
locale: {
  default: "tr",
  messages: {
    tr: {
      MAINTENANCE_MODE: "Ayar değişiklikleri bakım bitene kadar kapalı.",
    },
    en: {
      MAINTENANCE_MODE: "Settings are unavailable during maintenance.",
    },
  },
}
```

## Kullanıcı mesajı ne içermemeli?

- stack trace
- store veya Redis anahtarı
- token, çerez, nonce veya OAuth code
- Discord ham hata gövdesi
- veritabanı sorgusu
- iç sınıf veya dosya yolu

## HTTP eşlemesi

Uygulama sabit hata kodunu uygun HTTP durumuna çevirir. Aynı kodu hem log hem kullanıcı mesajı olarak kullanma; operatör bağlamı ile son kullanıcı metni ayrı kalmalı.

## Dil seçimi

Dil kaynağını sırayla belirleyebilirsin:

1. kullanıcı tercihi
2. Discord locale
3. dashboard locale
4. `locale.default`

İstemciden gelen serbest dil etiketini dosya yolu veya dinamik import için kullanma; desteklenen dillerden birine eşleştir.
