# Hatalar ve diller

GuildGate Türkçe ve İngilizce hata metinleriyle kullanılabilir. Projene özel metni hata kodu üzerinden değiştirebilirsin.

```ts
locale: {
  default: "tr",
  messages: {
    tr: {
      MAINTENANCE_MODE: "Ayarlar bakım sırasında geçici olarak kapalı.",
    },
  },
}
```

## Kullanıcı yanıtı

Yanıtta kısa hata kodu ve anlaşılır mesaj ver. Şu değerleri dışarı çıkarma:

- OAuth belirteci
- Oturum belirteci
- CSRF sırrı
- Bot belirteci
- Veritabanı sorgusu
- Stack trace
- Dahili dosya yolu

## Sunucu günlüğü

Kullanıcı mesajı kısa kalabilir. Sunucu günlüğünde korelasyon kimliği, işlem adı, kaynak, süre ve güvenli hata sınıfı bulunmalıdır. Üstbilgi ve çerezleri günlük filtresinden geçir.
