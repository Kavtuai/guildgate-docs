# Test ve yayın doğrulaması

GuildGate `1.1.0` final kaynak paketi `npm run release:verify` ile doğrulandı. Aynı zinciri uygulama veya custom adapter release'inde de temel al.

## Release zinciri

```bash
npm run release:verify
```

Paket script sırası:

```text
typecheck
npm test
coverage
security verification
load harness
npm pack --dry-run
```

`npm test` kendi içinde temiz build, doküman kontrolü ve deterministik testleri çalıştırır.

## Final test sonucu

| Sonuç | Adet |
| --- | ---: |
| Geçen | 76 |
| Başarısız | 0 |
| Yerelde atlanan live-service tanımı | 2 |
| İptal | 0 |

İki live-service tanımı gerçek PostgreSQL ve Redis daemon gerektirir. GitHub Actions disposable PostgreSQL 17 ve Redis 8 servisleriyle bu testleri etkinleştirir.

Final deterministik suite, son düzeltmeden sonra beş kez art arda aynı sonuçla çalıştırıldı: 76 geçen, 0 başarısız, aynı iki live-service tanımı yerelde atlandı.

## Coverage

| Ölçüm | Sonuç | Eşik |
| --- | ---: | ---: |
| Satırlar | 86.56% | 80% |
| Dallar | 77.15% | 70% |

Coverage düşüşü release'i durdurur. Yalnızca oranı yükseltmek için davranışsız test yazma; yarış, rollback, reservation ve transport sınırlarını test et.

## Load regression

Default release harness:

| İşlem | Eşzamanlılık | Hata | Throughput | p50 | p95 | p99 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 5.000 | 10 | 0 | 14,690.15/s | 0.60 ms | 1.29 ms | 2.37 ms |

Ek referanslar 10.000/20 ve 20.000/32 koşullarında sıfır hata verdi. Bunlar memory regression ölçümleridir; network, PostgreSQL, Redis veya Discord latency içermez ve production kapasite sözü değildir.

## Package consumer testi

Final tarball boş bir projeye lifecycle scriptleri kapalı olarak kuruldu. Kontroller:

- 16 public export yolu import edildi
- 3 CLI help komutu başarıyla çıktı
- test harness session oluşturdu
- idempotent action bir kez çalıştı ve saklanan sonucu replay etti

Consumer sonucu `CONSUMER_TEST_PASSED` oldu.

## Service integration

CI şu yolları gerçek servislerle doğrulamalıdır:

- PostgreSQL migration ve store contract
- nested transaction/savepoint
- advisory-lock rate limit
- idempotency reservation compare-and-set
- atomik session cap
- Redis cache retag ve tag TTL
- lease renew/release owner kontrolü
- outbox claim recovery
