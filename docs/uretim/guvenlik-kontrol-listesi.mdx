# Üretim güvenlik kontrol listesi

## Kimlik ve sırlar

- [ ] `baseUrl` ve Discord callback HTTPS kullanıyor.
- [ ] Origin listesinde HTTP, localhost ve wildcard yok.
- [ ] CSRF sırrı ile audit salt farklı ve yeterince uzun.
- [ ] OAuth token keyring kaynak kodunun dışında tutuluyor.
- [ ] Bot token, client secret ve store bağlantıları istemci bundle'ına girmiyor.

## Oturum

- [ ] Çerez `HttpOnly` ve `Secure`.
- [ ] Mutlak süre, idle süre, rotasyon ve kullanıcı oturum sınırı tanımlı.
- [ ] Kullanıcı oturumlarını topluca iptal etme yolu test edildi.
- [ ] Oturum iptali WebSocket/SSE bağlantılarını da kapatıyor.

## Store

- [ ] Session, OAuth credential, audit, outbox ve policy kalıcı store kullanıyor.
- [ ] Rate limit, idempotency, cache ve kilit tüm instance'lar tarafından paylaşılıyor.
- [ ] OAuth state consume işlemi atomik.
- [ ] Kilit renewal ve fencing testi geçti.
- [ ] Audit/outbox uygulama değişikliğiyle aynı transaction'a girebiliyor.

## Uygulama

- [ ] Kullanıcı ve bot izinleri ayrı kontrol ediliyor.
- [ ] Optimistic revision eski güncellemeyi reddediyor.
- [ ] Abort sinyali Discord, Redis ve DB çağrılarına taşınıyor.
- [ ] Kullanıcı yanıtları stack trace ve iç hata ayrıntısı içermiyor.
- [ ] Reverse proxy güven sınırı açıkça yapılandırıldı.

## Doğrulama

```bash
npm run typecheck
npm test
npm run pack:check
npx guildgate-doctor --json
```
