# Fastify ve Express

GuildGate HTTP çatısı kurmaz. Bağdaştırıcılar, mevcut uç noktanın istek ve yanıt nesnelerini işlem tanımına taşır.

## Fastify

```ts
import {fastifyActionHandler} from "@kavtuai/guildgate/fastify";

fastify.patch(
  "/api/guilds/:guildId/settings",
  fastifyActionHandler(gate, updateSettings),
);
```

## Express

```ts
import {expressActionHandler} from "@kavtuai/guildgate/express";

app.patch(
  "/api/guilds/:guildId/settings",
  expressActionHandler(gate, updateSettings),
);
```

## Uç noktadan önce karar verilecekler

- Proxy arkasında istemci IP'sini yalnızca güvenilen proxy katmanından çöz.
- JSON gövde sınırını HTTP çatısında tanımla.
- Genel hata yakalayıcıda stack trace'i kullanıcıya gönderme.
- Üretim kimlik çerezlerini HTTPS dışında açma.
