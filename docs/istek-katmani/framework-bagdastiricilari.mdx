# Framework bağdaştırıcıları

GuildGate çekirdeği framework nesnelerine doğrudan bağlı kalmaz. Bağdaştırıcılar istek, çerez, header, IP, abort sinyali ve yanıt biçimini çekirdek bağlamına çevirir.

## Fastify

`fastifyActionHandler` action'ı Fastify route handler olarak kullanır.

```ts
import {fastifyActionHandler} from "@kavtuai/guildgate/fastify";

fastify.patch(
  "/api/guilds/:guildId/settings",
  fastifyActionHandler(gate, updateGuildSettings),
);
```

## Express

`expressActionHandler` aynı action'ı Express middleware zincirine bağlar.

```ts
import {expressActionHandler} from "@kavtuai/guildgate/express";

app.patch(
  "/api/guilds/:guildId/settings",
  expressActionHandler(gate, updateGuildSettings),
);
```

## Hono

Paket Hono için de bağdaştırıcı içerir. Kurulu sürümün `exports` alanı ve TypeScript otomatik tamamlaması üzerinden alt yol adını doğrula; dahili dosya yoluna bağlanma.

## Uygulamanın vermesi gerekenler

- Güvenilir istemci IP çözümü
- Oturum ve CSRF header/çerez eşlemesi
- Abort sinyalinin aşağı katmanlara aktarılması
- Hata kodunun kullanıcı mesajına çevrilmesi
- Framework log'una sır veya iç hata ayrıntısı yazmama

Bağdaştırıcıyı ince tut. Ürün kuralını route dosyasına geri taşıma; action ve servis katmanında tut.
