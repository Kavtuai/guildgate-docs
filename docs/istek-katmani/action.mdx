# `action()` işlem tanımı

`gate.action()` bir yazma isteğinin girdi, kaynak, yetki, dayanıklılık ve kayıt kararlarını aynı tanımda tutar.

```ts
const updateSettings = gate.action({
  name: "guild.settings.update",
  parse(value) {
    const body = parseBody(value);
    return {
      guildId: body.guildId,
      revision: body.revision,
      settings: body.settings,
    };
  },
  resource: (input) => ({
    type: "guild",
    id: input.guildId,
  }),
  rateLimit: {
    limit: 20,
    windowMs: 60_000,
    key: (context, input) => `${context.userId}:${input.guildId}`,
  },
  idempotency: {
    ttlMs: 10 * 60_000,
    scope: (context, input) => `${context.userId}:${input.guildId}`,
  },
  concurrency: {
    key: (_context, input) => `guild-settings:${input.guildId}`,
    ttlMs: 8_000,
    waitMs: 500,
  },
  timeoutMs: 5_000,
  authorize: (context, input) =>
    canManageGuild(context.userId, input.guildId),
  execute: (context, input) =>
    saveGuildSettings(context, input),
});
```

## `parse`

Ham gövdeyi dar bir tipe çevir. Bilinmeyen alanları at, uzunluk ve enum sınırlarını burada uygula. Yetki kontrolünden önce veri doğrulaması yapman, gereksiz Discord ve store çağrılarını azaltır.

## `resource`

Rate limit, idempotency, kilit, audit ve realtime olayları aynı kaynağı kullanır. Kaynak kimliğini kullanıcı girdisinden olduğu gibi loglama; önce doğrula.

## `authorize`

Kullanıcının Discord sunucusuna erişimini ve gerekli izin bitini yazma anında yeniden çöz. Botun aynı işlem için gereken iznini ayrıca kontrol et.

## `execute`

Uygulama değişikliği burada çalışır. Transaction, optimistic revision ve Discord rol hiyerarşisi uygulama servisinin sorumluluğunda kalır.
