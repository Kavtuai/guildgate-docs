# Bellek ve Redis

Bellek deposu yerel test için uygundur. Birden fazla sunucu sürecinde ortak durum sağlamaz ve süreç kapanınca kayıtları kaybeder.

Kısa ömürlü kayıtları Redis'e taşıyabilirsin:

```ts
import {
  composeStores,
  createMemoryStoreBundle,
} from "@kavtuai/guildgate";
import {
  createRedisEphemeralStores,
  fromNodeRedis,
} from "@kavtuai/guildgate/redis";

const temporary = createRedisEphemeralStores(
  fromNodeRedis(redis),
  {prefix: "mybot:guildgate"},
);

const stores = composeStores(
  createMemoryStoreBundle(),
  {
    ...temporary,
  },
);
```

## Redis'e uygun kayıtlar

- OAuth `state` kayıtları
- Kısa süreli `nonce` kayıtları
- İstek sınırı sayaçları
- Tekrarlı istek kayıtları
- Dağıtık kaynak kilitleri
- Geçici gerçek zamanlı bağlantı durumu

## Prefix seçimi

Aynı Redis kümesini birden fazla uygulama kullanıyorsa proje ve ortam adını prefix'e ekle:

```text
fieldbot:production:guildgate
fieldbot:staging:guildgate
```

Bellek deposu bileşimi öğrenmek ve test etmek için kullanışlıdır. Yeniden başlatma sonrasında korunması gereken kayıtları kalıcı depoya bağla.
