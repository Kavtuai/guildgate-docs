# Bellek ve Redis

## Bellek store'ları

`createMemoryStoreBundle()` yerel geliştirme, örnek ve birim testi için hızlı bir başlangıç sağlar.

```ts
const stores = createMemoryStoreBundle();
```

Süreç kapanınca tüm kayıtlar silinir. Birden fazla instance aynı veriyi paylaşmaz. Bu nedenle production oturumu, OAuth kaydı, audit, outbox veya dağıtık kilit için bellek store'u kullanma.

## Redis store'ları

`createRedisEphemeralStores()` rate limit, cache, idempotency, OAuth state ve kilit gibi kısa ömürlü kayıtları merkezi Redis'e bağlar.

```ts
import {
  createRedisEphemeralStores,
  fromNodeRedis,
} from "@kavtuai/guildgate/redis";

const ephemeral = createRedisEphemeralStores(
  fromNodeRedis(redis),
  {prefix: "guildgate:production"},
);
```

## Ad alanı

Production, staging ve test aynı Redis'i kullanıyorsa ayrı prefix seç. Paket sürümü yerine ortam ve uygulama kimliğini kullan; sürüm yükseltmesi eski kayıtları gereksiz yere erişilmez bırakmasın.

## Kilit güvenliği

Redis kilidi TTL ile bırakıp unutulan basit bir anahtar olmamalı. Yenileme ve fencing token desteği, geciken iş sahibinin yeni sahibin ardından yazmasını engeller.
